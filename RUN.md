# Native-size simulator screenshots (one bounded capture run)

Workflow run: https://github.com/drelly3/arc-tracker-ios-prototype/actions/runs/45760477409

XCUITest drive of the Capacitor shell on a 6.9-inch iPhone simulator with a clean status bar.
Files named store-* are candidate store screenshots; 01 to 06 are evidence for the unsaved-changes
warning (Cancel stays in Setup, OK saves) and for the hidden Home Screen step on Start Here.
Sample data only ("Alex", "Read one page", "Plan the next day", "10 push-ups"). The production API
host was pinned to 127.0.0.1 on the runner for this run. Not tested: real devices, reminders delivery,
CSV file selection, camera.
